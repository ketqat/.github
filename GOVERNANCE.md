# Governance

KetQat uses GitHub-native collaboration:

- Issues track actionable work.
- The organization Project tracks status, priority, area, effort, target, and ownership.
- RFCs capture proposals under discussion.
- ADRs capture accepted architecture and scientific-contract decisions.
- `ketqat-planning/CONTEXT.md` is the concise entry point for humans and Codex agents.

Implementation behavior remains canonical in code, tests, schemas, migrations, and repository-specific README files.
