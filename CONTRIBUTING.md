# Contributing to KetQat

KetQat welcomes focused contributions that improve reproducible QEC and quantum-algorithm research workflows.

Use issues for actionable work. Use RFCs in `ketqat-planning` for cross-repository proposals or decisions that are still under discussion. Material architecture or scientific-contract decisions should be recorded as ADRs after acceptance.

Pull requests should link an issue, state scope and non-scope, describe tests run, and call out public schema, security, and scientific-validity impact.
