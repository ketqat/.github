# KetQat organization health files

This repository owns the public KetQat organization profile, shared issue forms, and default pull request template.

KetQat is focused on reproducible research infrastructure for quantum error correction and quantum algorithms. It does not provide QPU access aggregation, a marketplace, billing, hardware-provider status monitoring, pricing aggregation, or persistent credential storage. It does support hardware characterization snapshots and user-initiated execution on hardware you already have access to, using credentials supplied per job and never stored.
