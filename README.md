# KetQat organization health files

This repository owns the public KetQat organization profile, shared issue forms, and default pull request template.

KetQat's current focus is recurring regression checks for small Qiskit software
teams: free local/CI comparison, with optional private team policy, baseline and
history management as the proposed paid service. The source CLI is available;
the hosted commercial flow is under review and not on sale. Existing research
records, public licenses and scientific limitations remain in force.

KetQat's own software subscription is in scope. QPU access resale, a hardware
marketplace, QPU billing and persistent provider credentials remain excluded.
Existing user-initiated research execution uses access the user already has;
it does not make KetQat a QPU broker.
